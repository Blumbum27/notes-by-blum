# Оболочка редактора

`EditorShell` принимает manifest и не владеет штрихами. Интеграция в маршруте:

- `notebook`, `onNotebookChange`: актуальный manifest и замена после завершённой записи repository.
- `activePage`, `onSelectPage(index)`: индекс страницы; редактор прокручивает свою ленту.
- `readOnly`, `onReadOnlyChange`: режим ввода.
- `toolbar`: центральная группа инструментов без собственного Host внешней строки.
- `children`: лента и её подпанель. Боковая панель занимает 300 точек и сдвигает содержимое.
- `onBeforeAction(): Promise<void>`: дождаться сохранения всех живых PKCanvasView перед экспортом, дублированием и переходом.
- `onClearPage`: команда очистки текущего канваса, отменяемая его undo manager.

Настройки: `src/shared/settings.ts`, `useSettings()` подписывает редактор на изменения,
`readSettings()` оставлен для синхронного чтения. `horizontal`, `fingerDrawing`, `newTabs`
должны применяться владельцами ленты/ввода/открытия документов.

Нативный рендер: `modules/notes-canvas/rendering.ts`, отдельный `NotesRenderingModule`.
`renderThumbnails` создаёт миниатюры и `thumbnails/cover.png`; вызывать также после
сохранения рисунка, поскольку manifest при изменении только PKDrawing не меняется.
`shareNotebookPDF` экспортирует выбранные ID (пустой массив = все страницы) и открывает
системный share sheet. Штрихи не передаются через JS. Бумага использует общий PaperView.

Базовый EditorScreen подключён к оболочке для нативной проверки. D заменяет эту
временную композицию редактором B, сохраняя перечисленные props.

## Границы текущей реализации

Добавление использует нативный popover с положением и превью бумаги. Экспорт имеет
форму PDF/PNG, имени и опций фона/аннотаций; share sheet открывается после onDismiss,
иначе UIKit теряет презентацию. Выбор страниц поддерживает групповой экспорт/удаление.
Список вкладок хранится в Documents/open-documents.json. Положение панели пока
действует в сеансе. Перестановка и импорт здесь не реализованы. Превью «Текущий»
учитывает blank/grid/ruled; dots и цвет бумаги требуют отдельной доводки.
Полная приёмка меню и повторного запуска остаётся обязательной.

Нативная проверка: симулятор 63116BCD-F7D5-468E-AE7D-8FEB061F419B, iPadOS 27,
820×1180 и 1180×820 точек, синтетический документ из четырёх страниц.
Просмотрены снимки в ~/Pictures/OpenCode/notes-by-blum/shell/:
add-final-portrait.png, add-landscape.png, export-form-portrait.png,
export-form-landscape.png, native-share-portrait.png, selection-landscape.png,
settings-sheet-portrait.png, settings-sheet-landscape.png, more-final-landscape.png.
Добавление blank после текущей страницы увеличило manifest с трёх до четырёх страниц;
PDF дошёл до системного share sheet. Форма экспорта и настройки в обеих ориентациях
не обрезаны; у миниатюр убраны перекрывающие текстовые кнопки.
Точное соответствие референсам не принято: экспорт использует grouped Form вместо
карточек формата, меню документа сокращено, центральный scaffold-инструмент «Ластик»
обрезается. PNG-экспорт, групповое удаление, ошибки записи и восстановление нескольких
вкладок после перезапуска ещё не проверены. onBeforeAction в временной композиции
не подключён: D обязан связать его с подтверждённым сохранением канвасов B.
