# Оболочка редактора

`EditorShell` принимает manifest и не владеет штрихами. Интеграция в маршруте:

- `notebook`, `onNotebookChange`: актуальный manifest и замена после завершённой записи repository.
- `activePage`, `onSelectPage(index)`: индекс страницы; редактор прокручивает свою ленту.
- `readOnly`, `onReadOnlyChange`: режим ввода.
- `toolbar`: центральная группа инструментов без собственного Host внешней строки.
- `children`: лента и её подпанель. Боковая панель занимает 300 точек и сдвигает содержимое.
- `onBeforeAction(): Promise<void>`: дождаться сохранения всех живых PKCanvasView перед экспортом, дублированием и переходом.
- `onClearPage`: команда очистки текущего канваса, отменяемая его undo manager.

Настройки: `src/shared/settings.ts`, `useSettings()` подписывает редактор на изменения,
`readSettings()` оставлен для синхронного чтения. `horizontal`, `fingerDrawing`, `newTabs`
должны применяться владельцами ленты/ввода/открытия документов.

Нативный рендер: `modules/notes-canvas/rendering.ts`, отдельный `NotesRenderingModule`.
`renderThumbnails` создаёт миниатюры и `thumbnails/cover.png`; вызывать также после
сохранения рисунка, поскольку manifest при изменении только PKDrawing не меняется.
`shareNotebookPDF` экспортирует выбранные ID (пустой массив = все страницы) и открывает
системный share sheet. Штрихи не передаются через JS. Бумага использует общий PaperView.

Полная композиция с редактором B выполняется агентом D; базовый EditorScreen каркаса
не переведён на новые props, чтобы не создавать конфликт с параллельной заменой B.

## Границы текущей реализации

Меню добавления использует системные вложенные меню вместо визуального каталога
шаблонов из референса. Экспорт сразу открывает PDF в share sheet, без промежуточной
формы имени/опций; native API уже принимает флаги фона и аннотаций. Выбор нескольких
страниц, перестановка, импорт и отдельные расширенные настройки Goodnotes не реализованы.
Вкладки живут в текущем JS-сеансе и не восстанавливаются после завершения приложения.
Визуальная приёмка должна выполняться на финальной композиции; standalone оболочка
без канваса не является подтверждением соответствия референсу.
