# notes by Blum — нативный блокнот для iPad и iPhone

Первая реализация базового блокнота на SwiftUI, PencilKit, PDFKit и StoreKit 2. Минимальная версия — iOS/iPadOS 17. Без внешних библиотек и сервера. Интерфейс на русском.

**Статус:** подготовлена версия для первой проверки релиза 1.0.0, исходники и Xcode-проект обновлены на Windows. Компиляция Swift, запуск на устройствах и покупки ещё не проверены. Публикация не выполнена. Название выбрано пользователем: Blumbum.

**Начните с [Windows → TestFlight](docs/WINDOWS-TO-TESTFLIGHT.md).** Там описан путь для пользователя без Mac, GitHub и Apple Developer: сначала реальная облачная сборка, затем подпись и TestFlight.

Включены тетради, обложки, папки, избранное, поиск, рукопись с настройкой инструментов в системной палитре, страницы и шаблоны, текст и изображения, PDF, локальное сохранение, корзина, резервные копии и код подписки.

Добавлены удобства письма: стирание быстрым зачеркиванием, опциональное выпрямление длинных линий, быстрые ручки, режим чтения, запоминание последней страницы, очистка рукописи с отменой и клавиатурные сокращения. Настройки — кнопка с ползунками под навигацией страниц. Подробности и ограничения: [новые функции письма](docs/WRITING-FEATURES.md).

Также реализованы полка повторно используемой рукописи, временная лазерная указка, миниатюры страниц, пять цветов бумаги и текстовые стикеры. Доступ — панель быстрых инструментов, меню ⋯ и панель объектов. Описание: [оформление и дополнительные инструменты](docs/NOTEBOOK-EXTRAS.md).

Добавлена галерея бумаги: 4 базовые разметки и 8 макетов, пять цветов, A4/A5/Letter/квадрат, ориентация, поля и шаг. [Описание](docs/PAPER-TEMPLATES.md), [автономный предпросмотр](previews/paper-gallery.html), [аудит исправлений](docs/AUDIT-2026-11-13.md). Предпросмотр показывает макеты, а не запущенное iOS-приложение.

## Как увидеть приложение на iPhone или iPad, если у вас Windows

Одних исходников недостаточно для установки: iOS-приложение нужно собрать средствами Apple и подписать. В этом архиве нет готового IPA.

1. Самый прямой путь — временный доступ к Mac с Xcode: свой, знакомого или удалённый Mac. Откройте `NotesByBlum.xcodeproj` и выполните шаги ниже. Для этого не нужно переносить разработку на Mac навсегда.
2. Для автоматической проверки без собственного Mac загрузите содержимое **этой папки** в корень GitHub-репозитория. Workflow `.github/workflows/ios.yml` соберёт проект и запустит XCTest на macOS runner. Наличие и условия использования runner проверьте в своём аккаунте. Workflow не публикует приложение и не выдаёт устанавливаемый IPA.
3. Для установки через TestFlight нужны подписанная сборка, аккаунт Apple Developer и настройка App Store Connect. Подготовлен отдельный ручной `.github/workflows/testflight.yml`; доступов и сертификатов в проекте нет. Workflow ещё не запускался.

## Первый запуск в Xcode

1. Используйте Xcode 26 с iOS SDK 26 или новее; это требование загрузки в App Store на 13 ноября 2026 года. Минимальная версия запуска приложения — iOS/iPadOS 17.
2. Откройте `NotesByBlum.xcodeproj`. Выберите схему `notes by Blum`, затем симулятор iPhone или iPad и Run.
3. Для физического устройства в Signing & Capabilities выберите свою Team, замените `app.blumbum.ios` на уникальный Bundle ID и включите Developer Mode на устройстве, если Xcode попросит.
4. Нажмите «+ Тетрадь», задайте название и шаблон. В редакторе используйте системную палитру снизу. Повторное нажатие на ручку открывает толщину, цвет выбирается рядом. На симуляторе пишите мышью при включённом «Рисовать пальцем».
5. В меню ⋯ находятся печатный текст, изображения, экспорт и подсказка. В списке страниц удерживайте строку для дублирования/удаления, «Править» позволяет менять порядок.
6. Удерживайте обложку в библиотеке для параметров, перемещения в папку и резервной копии.

## Подписка

Бесплатно — 3 тетради, включая корзину; все основные инструменты и страницы доступны. Подписка снимает лимит тетрадей. При окончании подписки записи не блокируются.

В App Store Connect создайте одну группу, два auto-renewable продукта одинакового уровня:

- `app.blumbum.plus.monthly`: один месяц;
- `app.blumbum.plus.yearly`: один год.

Цена, описание, доступность и договоры настраиваются в App Store Connect. Без продуктов приложение продолжает работать бесплатно и не показывает выдуманные цены. Для локальной отладки можно создать StoreKit Configuration File в Xcode с этими ID и подключить его к схеме Run. Для выпуска требуется Sandbox-проверка реальных продуктов; отдельная серверная проверка покупок в этой версии не используется. Доступ определяется подтверждёнными currentEntitlements, включая льготный период оплаты. Статус обновляется при транзакциях, возвращении в приложение и раз в минуту.

Перед дистрибуцией заполните `Blumbum/Resources/AppConfiguration.json`: реальное имя владельца, email, HTTPS-страницы поддержки и политики. Release не разрешает покупки без этих данных. Кнопки покупок показывают локализованное название, цену и период из StoreKit.

## Проверки

На Windows или macOS с Python 3:

```text
python scripts/verify_project.py
python -B scripts/test_release_tools.py
python -B scripts/test_paper_catalog.py
python -B scripts/build_paper_preview.py
node scripts/test_paper_preview.js
```

Команда проверяет структуру проекта и ресурсы; она не проверяет Swift на ошибки типов.

На Mac:

```bash
bash scripts/ci-test.sh
```

Или Product → Test в Xcode. Подготовлено 56 XCTest-сценариев хранения, восстановления, импорта, валидации, жестов, отмены, совместимости старых данных, элементов и рендеринга, а также UI-сценарий создания тетради, добавления страницы, режима чтения, указки и последней страницы после перезапуска. Скрипт тестирует iPhone и iPad и сохраняет screenshot-вложение в `.xcresult`. Эти нативные тесты пока не запускались. Локально прошли 11 Python-тестов и проверка автономного предпросмотра в Node на 1440 сочетаниях с проверкой обработчиков интерфейса.

## Файлы проекта

- `Blumbum/Models/Notebook.swift` — переносимая модель версии 1.
- `Blumbum/Services/LibraryStore.swift` — хранение, импорт, резервные копии.
- `Blumbum/Services/PageRenderer.swift` — бумага, PDF и экспорт.
- `Blumbum/Services/SubscriptionStore.swift` — StoreKit 2.
- `Blumbum/Views/` — библиотека, холст, страницы, объекты, формы и подписка.
- `docs/PRODUCT.md` — функции, ограничения, последующие этапы.
- `docs/RELEASE.md` — действия для TestFlight и App Store, ручная приёмка.
- `docs/VALIDATION.md` — фактически выполненные проверки.
- `docs/WINDOWS-TO-TESTFLIGHT.md` — настройка аккаунтов, CI, подписи и загрузки.
- `docs/store/` — черновики описания App Store, политики и поддержки.
- `scripts/generate_project.py` — воспроизводимая генерация Xcode-проекта без сторонних пакетов.

После добавления Swift-файлов перегенерируйте проект: `python scripts/generate_project.py`. Генератор перезаписывает project.pbxproj и общую схему; пользовательские настройки Team лучше внести после генерации или перенести в генератор.

**Данные:** `Application Support/Blumbum/library.json`, предыдущее сохранение `library.previous.json` и `assets/`. При повреждении основного файла восстанавливается предыдущая валидная версия; повреждённый файл удерживается отдельно. Новая, неизвестная версия формата никогда не заменяется старой. Очистка вложений учитывает резервные состояния. Рукопись сохраняется в формате PencilKit. Экспорт `.listnote` переносит редактируемую тетрадь с вложениями. Экспорт PDF выполняется в фоне и не заменяет резервную копию. Перед удалением приложения экспортируйте тетради наружу. Синхронизации iCloud в этой версии нет.

Название приложения и Xcode-проекта: notes by Blum (`NotesByBlum.xcodeproj`, схема `NotesByBlum`). Внутренние модули Blumbum, Bundle ID, ID покупок и имена локального хранилища сохранены для совместимости данных.
