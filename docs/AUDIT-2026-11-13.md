# Ревизия notes by Blum — 13 ноября 2026

Проверены исходники моделей, хранилища, импорта/экспорта, холста и жестов, элементов, изображений, подписки, экранов, конфигурации Xcode и скриптов CI. Это **статическая ревизия с доступными переносимыми проверками**, а не подтверждение безошибочной работы iOS-приложения. Swift compiler, Apple SDK, симулятор и физический Pencil в текущей Windows-среде отсутствуют.

## Найденные проблемы и внесённые исправления

| Проблема в исходниках | Что изменено |
|---|---|
| При отсутствии основного library.json приложение не восстанавливало существующую предыдущую копию | Добавлено восстановление и уведомление; пустая библиотека не подставляется вместо доступной копии |
| Более новая версия могла не декодироваться до проверки номера версии и вызывать откат на старый backup | Заголовок версии читается отдельно до остальных полей; неизвестная версия блокирует запись |
| Неожиданно изменённый, повреждённый PKDrawing на диске мог перезаписать хорошую предыдущую копию при следующем сохранении | Контрольная сумма известных валидных байтов; при отличии — повторная полная проверка до замены backup |
| Весь PencilKit-контент заново декодировался на каждом автосохранении | Валидные известные данные не декодируются повторно; метаданные проверяются на входе, внешний контент проверяется полностью |
| Ошибка импорта после записи части вложений оставляла файлы-сироты | Добавлен откат новых файлов при неуспешном commit, порядок проверки вложений детерминирован |
| Очистка вложений не учитывала незавершённые фоновые операции | Добавлены счётчики активных читателей; миниатюра/экспорт удерживают нужные файлы до завершения или отмены |
| Ссылка изображения могла указывать на PDF или некорректный путь | Проверка допустимых имён, расширений и согласованности PDF-ссылки/номера страницы |
| Отклонённый хранилищем рисунок мог остаться на холсте как будто он сохранён | Обратная связь Bool от модели; отказ восстанавливает предыдущую допустимую рукопись и сбрасывает несовместимую историю отмены |
| Программное изменение холста регистрировалось до подтверждения модели | Изменение предварительно принимается моделью, затем применяется на холсте и в Undo |
| Повторное «Применить» после ошибки записи новой страницы могло добавить дубликаты в память | Вставка страницы и применение бумаги используют атомарный commit до изменения опубликованной библиотеки |
| Изменение размеров пустого листа оставляло прежний размер UIKit-холста | Идентичность холста включает размер страницы; смена формата пересоздаёт пустой холст |
| Миниатюра могла сохранять старый вид после изменения оформления/содержимого | Добавлено обновление по изменению данных страницы с отменой старого задания |
| PNG всегда преобразовывался в JPEG, теряя прозрачность | Изображения с альфа-каналом сохраняются как PNG; остальные — JPEG |
| На низких PDF-страницах вычислялась отрицательная высота вставленного фото | Общая функция вписывания с положительным размером и центрированием |
| UI-слайдеры могли получать значение вне своего диапазона после импорта | Значения для управления ограничиваются диапазоном; данные не перезаписываются до действия пользователя; диапазон шрифта согласован с моделью |
| CGPDFPage не рисовал отдельные PDFKit-аннотации | Видимые аннотации дополнительно рисуются в page space после основного содержимого |
| Размер PDF брался через другой API, чем трансформация рендера | Импорт использует raw mediaBox и intrinsic rotation того же CGPDFPage, что и renderer |
| Новые инструменты SDK могли создавать рукопись, недоступную на минимальной iOS 17 | На PKCanvasView и PKToolPicker установлен максимум content version 2 для создаваемых штрихов |
| Жест мог распознаваться при рисовании акварелью или мелком | Жесты ограничены ручкой, карандашом, монолинией и перьевой ручкой; рисовальные кисти и маркер не становятся целями автоматического стирания |
| «Такой же лист» мог менять положение линий старой бумаги | Для старых страниц сохранены прежние координаты и необязательные nil-поля; явный выбор нового оформления отделён от копирования |
| Ошибка применения оформления была не видна в окне выбора | Добавлено локальное сообщение; при ошибке commit изменения не вносятся |
| Временные копии экспорта могли накапливаться | При обслуживании очищаются только собственные временные pdf/listnote старше 7 дней; пользовательские сохранённые файлы не затрагиваются |

Если оба снимка недоступны, добавлен путь восстановления из .listnote: копия полностью проверяется в отдельном контейнере, исходная библиотека сохраняется целиком отдельно. Маркер транзакции позволяет завершить или откатить прерванную замену при следующем запуске. Неверная копия не изменяет исходники. Подготовлены сценарии восстановления, включая прерывание; они ещё не запущены на iOS.

Ни один пункт этой таблицы не означает успешный прогон на iOS: для исправлений подготовлены регрессионные сценарии, но их выполнение требует Apple SDK.

## Бумага и макеты

Добавлен единый каталог: 4 базовые разметки и 8 структурированных макетов. Пять цветов, 4 стандартных формата, ориентация, поля 16–64 пт, шаг 16–48 пт. Предпросмотр, экран, миниатюры и PDF используют общий native renderer. Размер заполненного листа защищён от изменения; подложку менять можно. Подробности: `PAPER-TEMPLATES.md`.

- Проверен синтаксис Python-скриптов. Сборка пакета ZIP проверяется на целостность.

## Что остаётся проверить

- Компиляция Swift и типы UIKit/PencilKit на Xcode 26+; подготовлены нативные unit/UI-тесты, но они не запускались.
- Реальные Undo-группы PencilKit, ложные срабатывания зачеркивания, паузы/давление Pencil, сочетание жестов и зума.
- Подписки StoreKit Sandbox: продление, отмена, refund, grace period, восстановление и работа без сети.
- PDF с нестандартными mediaBox/cropBox, поворотами и аннотациями без appearance stream, а также формы и ссылки. В экспорт они не переносятся как интерактивные объекты.
- Нагрузочная проверка большой библиотеки. Она всё ещё хранится единым JSON; постраничное хранилище и профилирование памяти остаются отдельной доработкой. Отложенная запись 350 мс не гарантирует сохранение незавершённого штриха при аварии.
- Визуальный QA именно нативного интерфейса, VoiceOver и Dynamic Type на iPhone/iPad. Предпросмотр каталога в браузере не заменяет его; headless-снимок браузера в этой среде получить не удалось.
- Подпись, TestFlight и App Review. Аккаунты/сертификаты/контакты владельца не настроены, приложение не опубликовано.

Проверенные API: [ограничение content version](https://developer.apple.com/documentation/pencilkit/pktoolpicker/maximumsupportedcontentversion), [версия 2 и iPadOS 17](https://developer.apple.com/documentation/pencilkit/pkcontentversion/version2), [рисование PDF-аннотаций](https://developer.apple.com/documentation/pdfkit/pdfannotation/draw(with:in:)).
