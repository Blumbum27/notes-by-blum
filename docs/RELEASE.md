# Подготовка TestFlight и App Store

Этот список фиксирует оставшуюся работу, а не подтверждает готовность приложения к отправке.

Для текущей ситуации (Windows, аккаунты ещё не созданы) начните с `WINDOWS-TO-TESTFLIGHT.md`. Подготовлен обычный CI и отдельный ручной workflow подписи и загрузки; оба ещё не запускались. Требуемый SDK загрузки на 13 ноября 2026 — iOS 26+, Xcode 26+; минимальная версия устройства остаётся iOS 17.

## 1. Сборка и устройства

- Получить доступ к Mac с актуальной версией Xcode. GitHub Actions позволяет проверить компиляцию и XCTest без своего Mac, но обычный simulator build не устанавливается на iPhone.
- Успешно выполнить build и все XCTest, устранить ошибки и предупреждения, затем проверить на физическом iPad с Pencil и iPhone.
- Выбрать собственные Team, Bundle ID и рабочее имя. Проверить доступность имени и создать запись в App Store Connect.
- Выполнить Archive для Generic iOS Device, Validate App и загрузить подписанный архив. Включить TestFlight, собрать обратную связь и исправить проблемы до App Review.

Apple описывает [загрузку сборок](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds-overview/). Xcode Cloud тоже требует первоначальной настройки из Xcode: [первый workflow](https://developer.apple.com/documentation/xcode/configuring-your-first-xcode-cloud-workflow).

## 2. Подписка и документы

- Настроить договоры, налоги и банковские данные; создать одну subscription group с месячным и годовым продуктом одинакового уровня доступа.
- ID должны совпадать с `SubscriptionStore.swift`. Указать цены и локализованные описания; не обещать ещё не реализованные функции.
- Проверить purchase, cancel, pending, renewal, expiry, revocation/refund, restore, отсутствие сети и запуск после смены Apple ID. Подписка не должна открываться по неподтверждённой транзакции.
- Проверить billing grace period в Sandbox. Код использует подтверждённые currentEntitlements, которые включают активную подписку и grace period; дополнительной блокировки по expirationDate нет. Grace period необходимо настроить в App Store Connect.
- Опубликовать политику конфиденциальности с реальными данными владельца и контактом поддержки. Ссылка на внутренний экран не заменяет публичный Privacy Policy URL в App Store Connect. Добавить эту публичную ссылку на экран подписки.
- Указать Support URL, возрастной рейтинг, данные о конфиденциальности и Export Compliance по фактической сборке. Проверить privacy report архива и используемые required-reason API.

Официально: [подписки Apple](https://developer.apple.com/app-store/subscriptions/), [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/).

## 3. Ручная приёмка

| Проверка | Ожидаемый результат |
|---|---|
| Перо, карандаш, маркер | Цвет и толщина меняются через палитру, штрихи соответствуют выбранному инструменту |
| Pencil и ладонь | Ладонь не рисует при режиме Pencil; двухпальцевые жесты не оставляют штрихов |
| Масштаб, поворот, Split View | Холст остаётся доступен, координаты чернил совпадают с бумагой |
| Отмена/повтор | Штрихи отменяются и возвращаются; смена страницы сбрасывает историю |
| Стирание зачеркиванием | Обычное письмо не удаляется; жест стирает только ожидаемые штрихи; один Undo возвращает их, Redo не показывает сам жест |
| Выпрямление линий | По умолчанию выключено; длинные линии выпрямляются, буквы/дуги/короткие штрихи сохраняются |
| Чтение и последняя страница | Чтение блокирует изменение содержимого; после перезапуска открывается последняя страница каждой тетради |
| Лазерная указка | След исчезает; жест не меняет рукопись, Undo, резервную копию или PDF; два пальца управляют листом |
| Мои элементы | Сохранение переживает перезапуск, повторная вставка создаёт независимые копии, Undo возвращает состояние до вставки |
| Цвета и стикеры | Настройки сохраняются в .listnote, одинаково видны на странице и в PDF; старые сохранения открываются |
| Миниатюры | Соответствуют содержимому страницы, большие PDF обрабатываются по очереди, уход из списка отменяет ненужные задачи |
| Добавление и перестановка страниц | Рисунок остаётся привязан к UUID страницы, а не её номеру |
| Уход в фон и перезапуск | Завершённые изменения сохраняются; при ошибке диска показывается сообщение |
| Папки, поиск, избранное | Фильтры показывают правильные тетради; поиск печатного текста работает |
| Удаление и восстановление | Корзина сохраняет содержимое; окончательное удаление требует подтверждения |
| Повреждённый library.json | Исходные данные не перезаписываются пустой библиотекой |
| PDF, включая 90°/270° и разные page boxes | Текст и рукопись совпадают на экране и в экспорте |
| Текст и фото | Позиции и размеры сохраняются, одинаковы на странице и в PDF |
| .listnote на новом устройстве | Импорт возвращает бумагу, рукопись, текст и вложения; копия получает новые UUID |
| Бесплатный лимит | 4-я тетрадь и обход через duplicate/import не доступны без подписки |
| Завершение подписки | Существующие тетради можно читать, менять и экспортировать |
| VoiceOver, крупный текст, iPhone SE | Кнопки доступны, основные действия не скрыты или обрезаны |
| Большие документы | Память, время импорта и экспорт соответствуют выбранным ограничениям |

## 4. До широкого релиза

Очистка неиспользуемых вложений, ограничения изображений, резервное сохранение и фоновый PDF-экспорт уже реализованы в коде. Требуется их проверка на устройствах, тестирование прерывания записи и нагрузочная проверка большой библиотеки. Для публичной подписки нужно подтвердить бизнес-модель и постоянную ценность продукта; число тетрадей пока её единственное платное преимущество.

Подготовить оригинальные скриншоты именно работающей сборки для iPhone и iPad, описание и заметки для ревьюера: где создать тетрадь, как открыть палитру, какой бесплатный лимит и как проверить подписку. Не использовать Goodnotes в названии, иконке и заявлениях об официальной связи. Применяется [правило Apple 4.1](https://developer.apple.com/help/app-review/guideline-reference/4-1-prevent-copycat-rejection).

Дополнительно проверить: все 12 макетов и 5 цветов на iPad/iPhone; ориентацию и смену формата пустой страницы; сохранение координат старой бумаги; перенос макета через .listnote и PDF. Проверить восстановление при отсутствии основного файла, повреждении обоих снимков, неверной копии и прерывании замены библиотеки. Исходная недоступная библиотека должна оставаться сохранённой отдельно.
