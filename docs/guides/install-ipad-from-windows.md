# Установка notes by Blum на iPad через Windows

Инструкция для агента, который помогает пользователю на Windows-ноутбуке.
Сценарий: на Mac собирают приложение → передают `.ipa` на Windows →
Sideloadly подписывает его бесплатным Apple Account и устанавливает на iPad.
Платная подписка Apple Developer и TestFlight для этого сценария не нужны.

Это инструкция, а не отчёт об успешной установке: данный сценарий ещё
не проверен на целевом Windows-ноутбуке и iPad. Не объявляй его проверенным
до фактического запуска приложения на устройстве.

## Как помогать

Давай одно конкретное действие или небольшой блок действий, затем проверяй
результат. Не перечисляй сразу все возможные ошибки. Если доступна автоматизация,
помогай непосредственно, но установку ПО и изменения системы согласовывай.
Не меняй код проекта ради установки готового файла.

## 1. Выясни исходное состояние

- Версия и архитектура Windows; для начала предпочтительна Windows 10/11 x64.
  На ARM не обещай совместимость без проверки текущих требований Sideloadly.
- Версия iPadOS: нашему приложению нужна iPadOS 26 или новее.
- Получен ли `.ipa`, откуда он взят и какой версии приложения соответствует.
- Установлены ли Sideloadly, iTunes и iCloud, из каких источников.
- Есть ли кабель с передачей данных и видит ли iTunes подключённый iPad.
- Есть ли уже установленная версия notes by Blum и важные заметки в ней.

## 2. Проверь готовность сборки с Mac

Нужен `.ipa` для **реального iPad**, не `.app` для симулятора. Это должна быть
автономная Release-сборка со встроенным JavaScript, без зависимости от Mac,
Metro или сервера разработки. На Windows приложение не компилируется:
Xcode, Node, Expo и исходники здесь не нужны.

Само наличие `.ipa` не доказывает, что сборка подходит. Если файл ещё не готов,
запроси его у агента на Mac; не выдавай запуск симулятора или development build
за готовую автономную сборку. Вместе с файлом желательно получить source SHA,
версию и Bundle ID. Передать файл можно через облако, мессенджер или флешку.

## 3. Подготовь Windows

1. Открой официальный сайт [Sideloadly](https://sideloadly.io/)
   и проверь актуальные требования и [FAQ](https://sideloadly.io/faq).
2. Скачай подходящий установщик Sideloadly с этого сайта.
3. По текущим требованиям Sideloadly нужны версии iTunes и iCloud с сайта
   Apple, ссылки на которые приведены на сайте Sideloadly, а не версии
   из Microsoft Store. При изменении требований следуй актуальной документации.
4. Если требуется заменить уже установленные программы, объясни причину,
   проверь важные данные и незавершённую синхронизацию, получи согласие.
   Не удаляй программы и их данные автоматически.
5. Установи согласованные компоненты; при необходимости перезагрузи ноутбук.

Не отключай антивирус, защиту Windows или проверку подписи драйверов.
Не используй случайные зеркала, чужие сертификаты и платные сервисы подписи.

## 4. Подключи iPad и установи приложение

1. Разблокируй iPad и подключи кабелем с передачей данных.
2. На iPad пользователь сам подтверждает «Доверять этому компьютеру»
   и вводит код-пароль. Сначала проверь определение устройства в iTunes.
   Не запускай восстановление, сброс, стирание или ненужную синхронизацию.
3. Открой Sideloadly, выбери нужный iPad в поле **iDevice**, добавь `.ipa`.
4. Объясни: Sideloadly — сторонняя программа, которой пользователь доверяет
   авторизацию Apple. Не обещай отсутствие риска. Apple Account не обязан
   совпадать с аккаунтом iCloud на iPad, но для обновлений нужен тот же аккаунт,
   которым подписана предыдущая установка.
5. Пользователь сам вводит Apple Account в Sideloadly, нажимает **Start**,
   вводит пароль и код двухфакторной аутентификации, если запрошены.
   Не проси присылать пароль или коды в чат, не сохраняй их в репозитории/логах.
6. Дождись завершения установки и попроси открыть приложение на iPad.

Если iPad показывает «Ненадёжный разработчик»: **Настройки → Основные →
VPN и управление устройством → профиль с использованной почтой → Доверять**.

Если требуется режим разработчика: **Настройки → Конфиденциальность
и безопасность → Режим разработчика → Включить**; подтвердить перезагрузку
и включение после неё. Если пункта нет, проверь после попытки установки.
Ориентируйся на фактические экраны: названия могут отличаться.

## 5. Обновления и семь дней подписи

- Бесплатный профиль действует **7 дней с выпуска**, не с первого запуска.
  После истечения приложение перестаёт запускаться до обновления подписи;
  это само по себе не означает удаления данных. Ограничения Apple описаны
  в [сравнении вариантов членства](https://developer.apple.com/support/compare-memberships/).
- Для продления можно повторно подписать и установить тот же `.ipa`.
  Пересобирать неизменённый код на Mac для этого не требуется.
- Новую версию устанавливай **поверх старой**, с тем же Apple Account
  и тем же итоговым Bundle ID. Если в Sideloadly задавали собственный ID,
  сохрани его. Не меняй ID ради обхода ошибки: получится отдельное приложение.
- **Не удаляй старое приложение:** заметки локальные. Перед обновлением важных
  данных выясни доступный способ резервного копирования и проверь его результат.
  Не утверждай, что экспорт или резервная копия уже реализованы. Если безопасное
  обновление подтвердить нельзя, остановись и согласуй дальнейшие действия.
- Автопродление требует включённого ноутбука, работающего **Sideloadly Daemon**,
  интернета и доступного iPad по USB либо заранее настроенному локальному Wi-Fi.
  Выключенный ноутбук подпись не продлевает.
- Wi-Fi настраивай после успешной установки по USB: в iTunes у устройства
  включи **Sync with this iPad over Wi-Fi**, примени настройку. Для обычного
  Wi-Fi-подключения ноутбук и iPad должны быть в одной локальной сети.
  Сам iPad без доступного компьютера подпись не продлевает.

## Ошибки и ограничения

- Устройство не видно: проверь разблокировку, доверие, кабель, USB-порт
  и определение в iTunes; затем компоненты Apple по официальному FAQ.
- Бесплатная подпись допускает до трёх таких приложений на устройстве.
  Другие приложения без согласия не удаляй. При лимите App ID не создавай
  новые идентификаторы наугад; посмотри точный текст ошибки и FAQ.
- Запроси точный текст ошибки или безопасный фрагмент лога. Перед пересылкой
  попроси скрыть почту, UDID, серийные номера, токены и содержимое заметок.
- Если приложение установилось, но вылетает или требует Metro, передай агенту
  на Mac версию/source SHA и описание сбоя. Не исправляй это удалением заметок.
- При отмене или ошибке не объявляй установку успешной: сохрани старую версию
  и данные, сообщи фактический результат и следующий безопасный шаг.

## Проверка результата и передача

Надписи **Done** в Sideloadly недостаточно. Попроси пользователя проверить:

1. Приложение открывается, закрывается и открывается повторно на iPad.
2. При недоступном Mac/Metro приложение работает; для проверки автономности
   можно временно отключить сеть на iPad после завершения установки/активации.
3. На синтетическом блокноте создание и сохранение переживают повторное открытие.
4. При обновлении прежние заметки доступны; не используй личные заметки для тестов
   и не отправляй их внешним сервисам.
5. Пользователь знает, как продлить подпись, и понимает, настроено ли автопродление
   или пока требуется ручная установка.

В отчёте укажи версию Windows, модель/iPadOS, версию или source SHA сборки,
результат установки и запуска, сохранность данных при обновлении,
состояние автопродления и оставшиеся ошибки. Отдельно отмечай непроверенное;
не выдавай подтверждение установки за полноценную приёмку всех функций приложения.
