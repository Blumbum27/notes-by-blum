# Бумага и макеты

## Как выбрать

- Новая тетрадь → «Выбрать бумагу и макет».
- Открытая обычная страница → ⋯ → «Бумага и макет».
- Кнопка добавления страницы → «Выбрать макет нового листа…».
- «Такой же лист» / «Новый лист с этой бумагой» копируют оформление и размер текущего листа, без его записей.

Цвет и разметка импортированного PDF не меняются. Для заметок рядом с ним можно добавить чистый лист нужного формата.

## Каталог

| Разметка | Назначение |
|---|---|
| Чистый лист | Свободные заметки и рисунки |
| Линейка | Обычное письмо |
| Клетка | Математика и схемы |
| Точки | Планы и наброски |
| Конспект Cornell | Колонки ключевых идей/записей и выводы |
| План дня | Задачи, три приоритета и заметки |
| План недели | Семь дней и итоги |
| Список задач | Строки с клетками для рукописных отметок |
| Заметки встречи | Участники, записи и следующие шаги |
| Две колонки | Сравнения и параллельные заметки |
| Нотный лист | Системы из пяти линий |
| Раскадровка | Шесть кадров с местом для подписей |

Чекбоксы и календарные блоки — разметка бумаги, не интерактивные задачи или календарь. Импорт произвольных пользовательских макетов в каталог пока не добавлен; PDF можно использовать как подложку через существующий импорт.

## Настройки

- Цвет: белый, кремовый, голубой, розовый или мятный.
- Формат: A4, A5, US Letter, квадрат; поддерживается и текущий нестандартный размер.
- Книжная или альбомная ориентация. Для квадрата она не нужна.
- Шаг разметки: 16–48 пунктов. Для нот меняется расстояние между линиями.
- Поля: 16–64 пункта.

Формат/ориентацию можно менять только у пустой страницы. Это предотвращает обрезку существующих записей. Макет, цвет и плотность меняются независимо от рукописи: штрихи остаются на тех же координатах. На заполненном листе смена шаблона может визуально не совпасть с прежними строками — это не автоматическое переформатирование почерка.

Настройки сохраняются в .listnote и применяются при экспорте PDF. Старые страницы без новых полей продолжают рисоваться на прежних координатах. Неизвестный ID будущего макета сохраняется, но отображается с базовой разметкой до появления этого макета в приложении.

## Предпросмотр на Windows

Откройте `previews/paper-gallery.html` в браузере. Можно менять макет, цвет, формат, ориентацию, шаг и поля. Каталог и палитра берутся из исходников приложения. Шрифты и движок SVG отличаются от UIKit, поэтому этот файл помогает выбрать макет, но не подтверждает корректность нативной сборки.

Пересоздать предпросмотр:

```text
python -B scripts/build_paper_preview.py
```

Источник структурированных макетов: `Blumbum/Resources/PaperTemplates.json`. Он включён в Xcode Resources. Рисование на странице, в миниатюрах и PDF выполняет `PaperTemplateRenderer.swift`.
