# Goodnotes на iPad: как устроен интерфейс

Снято с iPad Air 11" (M3), iPadOS 26.7.2, Goodnotes 7.1.14, русская локализация, бесплатный тариф. Логические размеры: портрет 820×1180 pt, альбом 1180×820 pt. Скриншоты сделаны через WebDriverAgent. В `NN-name.tree.txt` рядом с каждым скриншотом лежит дерево accessibility: тип, подпись и рамка в pt.

Файлы — личный референс. В приложение они не копируются. В кадрах видны реальные документы владельца.

## Библиотека

### Каркас
- Шапка: слева круглая кнопка «Показать боковое меню». Справа в одной плавающей капсуле «Поиск», «Уведомления» и аватар «Меню».
- Крупный заголовок раздела («Документы»).
- Строка управления под заголовком. Слева «Фильтр» с текущим значением («Все»). Справа синяя капсула «+ Создать», затем кнопка вида (иконка сетки или списка, `Сгруппированные опции: сортировка, параметры вида, выбор файлов`), разделитель и статус облака.
- Внизу плашка-предупреждение о резервном копировании («Резервное копирование приостановлено…», кнопки «Не сейчас» и «Войти в Google Drive»). У нас аналог — локальное напоминание о резервной копии, без облака.

### Боковое меню (`01-library-sidebar`)
- Плавающая скруглённая панель шириной 320 pt. Сверху справа кнопка «Скрыть боковое меню».
- Пункты с иконкой и подписью: Документы, Избранное, В общем доступе, Маркетплейс. У активного пункта серая скруглённая подложка и цветная иконка.
- Корзины в меню нет: она в меню аккаунта.
- В портрете панель сдвигает контент вправо и сетка перестраивается в 2 колонки. Это не оверлей.

### Сетка (`01`, `06`)
- Портрет — 4 колонки, ячейка 180×267 pt, превью 160×172.
- Папка — цветная иконка папки. Документ — обложка или первая страница с тенью.
- Звезда «избранное» в правом верхнем углу превью: контурная или залитая красным.
- Под превью: название + `⌄` (кнопка меню элемента), дата изменения («Сегодня, 11:53», «1 сент. 2026 г., 22:37»), опционально статус «Только чтение» с иконкой перечёркнутого карандаша.
- Угловой бейдж синхронизации на превью — облачный, нам не нужен.

### Список (`06-library-list`)
- Строка: маленькое превью, название, дата. Справа `⌄` (меню), звезда, для папок `›`. Разделители между строками.

### Фильтр (`03-library-filter`)
- Всплывающее меню: Все / Документы / Папки, у выбранного галочка.

### Вид и сортировка (`05-library-view-options`)
- Меню из трёх групп:
  - «Выбор элементов» (режим множественного выбора);
  - Сетка / Список;
  - Дата создания / Последнее изменение / Имя / Тип.
- У активной сортировки галочка и стрелка направления ^. Повторное нажатие меняет направление.

### Создать (`04-library-create`)
- Поповер под кнопкой. Верхний ряд плиток: Блокнот, Цифровая доска, Текстовый док-т. Второй ряд: Импорт, Быстрая аудиозапись.
- Затем список: QuickNote, Сканировать документы, Набор карточек, Изображение, Сделать фото. Отдельно: Папка. Отдельно: Импорт из облачных хранилищ.
- На бесплатном тарифе у платных пунктов бейдж-замок. У нас ограничений нет.
- Сейчас «Блокнот» на этом аккаунте открывает только системный алерт «Лимит бесплатных блокнотов исчерпан» (Отменить / Купить). Поэтому лист создания блокнота снять нельзя. Выбор бумаги для нового блокнота смотрите в разделе «Шаблоны блокнотов» и на скринах App Store.

### Меню документа (`07-item-menu-document`)
- Поповер. Сверху редактируемое поле с названием (переименование). Затем: Дублировать, Переместить, Преобразовать в цифровую доску, Открыть в новом окне, Экспорт, Ссылка общего доступа, Добавить защиту, Отправить в корзину (красным).

### Меню папки (`08-item-menu-folder`)
- Поле названия.
- Группа: Настроить цвет, Добавить значок (эмодзи-значок на папке).
- Группа: Переместить, Открыть в новом окне, Экспорт, Отправить в корзину.

### Меню аккаунта (`09-account-menu`)
- Поповер справа.
- Карточка профиля («Бесплатная версия», «Учётная запись») и промо подписки — нам не нужны.
- Группа: Настройки, Управление шаблонами блокнотов, Облако и рез. копии, Integrations, Корзина.
- Группа внешних ссылок: Руководство пользователя, Сообщить о проблеме, Оценить в App Store.

### Избранное (`02-favorites`)
- Тот же каркас с заголовком «Избранное», без «+ Создать».
- Показывает избранные папки, документы и отдельные страницы. Страница — это превью страницы с красной закладкой и мини-обложкой документа в углу; подпись «Название - Р.2».

## Настройки (`10`–`14c`)
- Модальное окно 540 pt по центру поверх затемнённой библиотеки. В шапке круглая кнопка «назад» ‹ слева, заголовок по центру, синяя круглая «Готово» ✓ справа. Группы — белые скруглённые карточки на сером фоне, подписи групп серым.
- Корень (`10-settings`). Группа 1: Редактирование документов, Конфиденциальность, Стилус и Palm Rejection. Группа 2: Язык, Рукописный ввод, Ассистент-корректор. Группа 3: Параметры уведомлений, Обратная связь и опросы, Устранение неполадок.
- **Редактирование документов** (`11`, `11b`):
  - переключатели: Автоблокировка экрана, Меню статуса iOS, Потянуть для добавления страницы, Показывать номер страницы, Показать слои;
  - выбор «Направление прокрутки»: Вертикально / Горизонтально;
  - переключатель «Превью штриха по наведению» (Pencil hover);
  - группа «Панель инструментов»: Настройка панели инструментов ›, «Расположение инструментов» (Вверху/…), «Позиция отмены и возврата» (Слева/…);
  - переключатели: Автопереход; Автоматически открывать новые импортированные документы; Открывать в новых вкладках; Преобразовать закладки в элементы структуры.
- **Стилус и Palm Rejection** (`12`): Стилус = Apple Pencil ›. Блок настроек Apple Pencil: «Прокрутка одним пальцем» и «Отключить». Блок Palm Rejection: «Чувствительность» (Высокая ›) и «Положение руки» с иллюстрацией.
- **Рукописный ввод** (`13`): «Индексация PDF и рукописных заметок» (поиск по содержимому), «Отправить рукописный образец».
- **Настройка панели инструментов** (`14`, `14b`, `14c`): сегменты «Инструменты» / «Аксессуары».
  - Инструменты: список с красным «удалить», иконкой, названием и ручкой перетаскивания. По порядку: Инструменты для письма («Настроить ›»), Ластик, Фигуры, Элементы, Клейкие заметки, Изображения, Текст, Лазерная указка. Подсказка «Хотя бы один инструмент должен оставаться видимым». При нехватке места часть уходит в меню «ещё». Кнопка «Восстановить стандартную панель».
  - Аксессуары: на панели «Записать и сделать сводку». Другие: Показать записи, Окно масштаба, Линейка, Time Keeper. Кнопка «Восстановить стандартные аксессуары».
- Свайп вниз по окну закрывает настройки.

## Редактор

### Шапка с вкладками (`20-editor-readonly-pdf`)
- Верхняя полоса (цвет темы, тёмно-синий) с вкладками открытых документов. Слева «Home» (домик). Каждая вкладка: название с обрезкой «…» и × справа. У активной белый фон, и рядом с названием ⌄ (меню документа).
- Вторая строка — панель документа:
  - слева: «Боковое меню» (миниатюры/структура), «Поиск», чип режима «Только чтение» / «Режим редактирования» (переключатель чтение ↔ правка);
  - справа: «Поделиться», «Ещё» (…).
- PDF-документ «Только чтение» — режим без панели инструментов.
- Страницы листаются вертикально и центрируются на сером фоне. Внизу слева плашка «1 из 264».

### Режим редактирования: панель инструментов (`21`, `22`)
- Блокнот «ракеты» тоже открылся в режиме «Только чтение» (`21`). Чип «Только чтение» переключает в режим правки. В режиме правки чип превращается в иконку «Режим редактирования».
- Строка панели (тёмно-синяя, как вкладки), в ландшафте 1180 pt:
  - слева: Боковое меню, Поиск, Режим редактирования;
  - центр: Выделение лассо (выбранный — белая скруглённая подложка, рядом ⌄), | разделитель, Письмо, Ластик, Фигуры, Элемент, Клейкая заметка, Изображение, Текст, Лазерная указка, | разделитель, «Записать и сделать сводку» (микрофон), «Аксессуары» (иконка + ⌄);
  - справа: Добавить (страницу), Поделиться, Ещё.
  - Кнопки 46×44 pt, иконки 24 pt, контурные белые.
- Под панелью — плавающая подпанель выбранного инструмента: белая капсула с тенью по центру, высота 45 pt.
- Слева сверху над страницей — плавающая капсула Отмена/Повторить (36×37 каждая). Неактивные — серые.
- Страница по центру на светло-сером фоне; бумага в клетку.

### Письмо (`22`, `23`, `24`, `25`)
- Подпанель: Ручка (выбрана, голубая подложка, ⌄), Карандаш, Маркер, Лента, Draw Shape (ручка-фигура) | 3 пресета толщины (пунктир/тонкая/толстая; значения «0.2 мм», «0.2 мм», «0.6 мм»; выбранная — серая подложка) | горизонтально прокручиваемые пресеты цвета (12 кружков; выбранный с ⌄ внутри).
- Повторный тап по выбранной ручке открывает поповер «Перьевая ручка» (`23`):
  - превью штриха (волна);
  - 3 типа плитками: Перьевая ручка, Шариковая ручка, Ручка-кисть (выбранная — белая плитка);
  - слайдеры с делениями: Острота кончика (Тупой), Чувствительность к нажиму (Мин.), Круглость кончика (Круглый), Стабилизация штриха (0%);
  - раздел «Настройки»: Настройки ручки ›, Ассистент-корректор ›, Помощник по математике ›; «Быстрый доступ к стилям» (Управление закладками, «1 стиль»).
- Тап по выбранному цвету открывает поповер «Цвет ручки» (`24`):
  - слева иконка настроек, справа кнопка «Править»;
  - сегменты Пресеты / Свои / История;
  - сетка 8×3 цветов (чёрный, серые, белый, фиолетовый, красные, розовые, оранжевый, синие, тёмно-синий, зелёные, жёлтые, коричневый, бордовый); выбранный с ✓; «+» для добавления.
- Маркер (`25`): та же подпанель, выбран Маркер (с ⌄). 3 толщины кружками (маленький/средний/большой) и пастельные цвета: жёлтый, розовый, голубой, чёрный, белый, персиковый…
- У каждого инструмента письма свои толщины и свой набор цветов. При переключении инструмента подпанель показывает его набор.
- Тап по пресету толщины только выбирает его, отдельного поповера нет.
- Карандаш (`23c`): толщины показаны карандашной текстурой, цвета — чёрный, тёмно-серый, серый и «+». Поповер «Стандартный карандаш»: превью штриха, «Настройки» — Снижение задержки (вкл.), Рисовать и удерживать ›, Отключить Apple Pencil.
- Лента (`23d`): непрозрачная полоса, которая скрывает написанное до тапа. Толщины — три прямоугольника, цвета — тёмный, узор со звёздами, оранжевый, зелёный, «+». Поповер «Лента»: превью «hide content», «Настройки» — Негибкая лента (вкл.), Реагировать на вращение пера (вкл.), Отключить Apple Pencil.
- Draw Shape (`23e`): ручка, которая выравнивает нарисованную фигуру. Толщины и цвета как у ручки. Поповер «Draw Shape»: «Настройки» — Требуется «Держать для привязки» (выкл.); «Дополнительные параметры» — Привязка к другим фигурам (вкл.), Цвет заливки (выкл.); Отключить Apple Pencil.

### Ластик (`26`, `26c`, `26d`)
- Подпанель: выпадающий «Точный ⌄» | иконка дополнительных настроек | 3 размера кружками (выбранный — синий контур).
- «Тип ластика» (`26c`): плитки Точный ластик / Стандартный ластик / Ластик для штрихов. Подпись «Возможность точно стереть мелкие детали».
- «Дополнительные настройки» (`26d`):
  - «Фильтр ластика» — переключатели Ручка, Карандаш, Маркер, Лента и «Выбрать все»; подсказка «Ластик будет игнорировать штрихи всех деактивированных инструментов»;
  - красная «Очистить страницу»;
  - переключатель «Автоперекл. на предыд. инструмент»;
  - «Отключить Apple Pencil».
- Повторный тап по активному ластику скрывает подпанель (`26b`).

### Лассо (`33`, `33b`, `33c`)
- Выбранное лассо — белая подложка с ⌄. Своей подпанели нет.
- Повторный тап открывает поповер «Лассо» (`33c`):
  - «Тип лассо»: две плитки — Прямоугольник и Произвольное (по умолчанию), выбранная на белой подложке;
  - «Захватывать при выделении»: список переключателей, все включены — Рукописный ввод, Изображения, Фигуры, Стрелки, Текстовые блоки, Формулы, Лента, Клейкие заметки;
  - внизу строка «Отключить Apple Pencil».
- Выделение рисуется только Apple Pencil: палец прокручивает страницу. Поэтому меню выделенного фрагмента через WDA не снято. Для своего приложения: штатный `PKLassoTool` и системное меню редактирования (Вырезать, Копировать, Удалить, Дублировать).

### Изображение
- Тап по «Изображение» открывает поповер «Изображения»:
  - справа сверху кнопка камеры;
  - сетка недавних фото из медиатеки (4 колонки, скруглённые квадраты);
  - внизу плавающая кнопка «Вставить из…».
- Скриншот не сохранён: в нём личные фото пользователя.

### Текст (`31`)
- Подпанель: цвет (кружок с ⌄) | размер «24 ⌄» | шрифт «Современный ⌄» | B/I | выравнивание | межстрочный интервал | рамка/фон поля (перечёркнутый квадрат = без заливки) | стиль текста | «Закрепить инструмент «Текст»» (булавка).
- Внизу тёмный тост с ⓘ: «Добавьте текст. поле касанием. Долгое нажатие > «Начать печатать» добавит текст к странице», с ×.
- Тап пальцем по странице создаёт пустое текстовое поле (`31b`): тонкая синяя рамка с курсором и системная клавиатура.
  - Над полем плавающая капсула форматирования: цвет (чёрный кружок с ⌄) | «24» | Aa (шрифт) | BI | выравнивание | список | ⋯.
  - Над клавиатурой полоса быстрых действий: отступ вправо/влево, маркированный и нумерованный список, выравнивание; справа B, I, U, S.
  - Инструмент временный: после создания поля в панели снова выбрано лассо.
  - Пустое поле исчезает при тапе мимо. Отмена при этом неактивна, документ не меняется.
- Поповеры капсулы:
  - цвет (`31c`): «Изменить цвет», слева кнопка настроек, справа «Править»; сегменты Пресеты / Свои / История; сетка 2×8 цветов, последний — «+»;
  - размер (`31d`): поле «24», слайдер и кнопки − / +;
  - шрифт (`31e`): Современный ✓, Классический, Технический, каждый своим начертанием; отдельной строкой «Другие шрифты…»;
  - стиль (`31f`): маленькая капсула B, I, U, S;
  - выравнивание (`31g`): по левому краю, по центру, по правому краю | межстрочный интервал;
  - ⋯ (`31h`): системное меню редактирования — Вырезать, Копировать, Вставить, «Вставить и согласовать стиль» | Форматирование ›, Выравн. и интервал ›, Отступ › | Ссылка.

### Добавить страницу (`36`)
- Поповер справа «Добавить страницу»:
  - сегменты Перед / После (по умолчанию) / Последняя страница;
  - «Недавние шаблоны» — подсказка «Показанные здесь шаблоны по возможности наследуют свойства текущей страницы»; горизонтальный ряд миниатюр: Текущий шаблон, Пустая страница, Линованная узкая;
  - список: Больше шаблонов…, Изображение, Сканировать документы, Сделать фото, Импорт.

### Ещё (`37`)
- Поповер «Ещё» справа. Карточка текущей страницы «Страница 4» с миниатюрой. Пункты: Добавить в избранное (закладка), Копировать страницу, Повернуть страницу ›, Добавить страницу к структуре, Изменить шаблон, Перейти к странице (1 – 5).
- Группа «Очистить или удалить страницу»: Удалить некоторые элементы ›, красные «Очистить страницу» и «Переместить страницу в корзину».

### Аксессуары (`34`)
- Поповер: Показать записи, Окно масштаба, Линейка, Time Keeper; отдельной карточкой «Настройка панели инструментов».

### Боковая панель страниц (`38`)
- Панель слева (~325 pt) сдвигает документ вправо; панель инструментов остаётся.
- Шапка: «…» слева, заголовок «Страницы», × справа.
- Сегменты-иконки: Страницы / Структура (outline) / Записи (аудио).
- Фильтр-чип «Все страницы ⌄» (голубой).
- Сетка 2 колонки миниатюр. У каждой закладка-флажок справа сверху, номер слева снизу, ⌄ (меню страницы) справа снизу. Текущая страница обведена синей рамкой.
- Последняя ячейка — пунктирная рамка с синим «+» (добавить страницу).
- Отмена/Повторить переезжают в подпанель инструмента (стрелка слева в капсуле).
- Меню страницы ⌄ под миниатюрой (`38b`): Добавить страницу перед, Добавить страницу после, Копировать, Дублировать, Повернуть, Переместить в…, Добавить страницу к структуре, Экспорт, Открыть в новом окне, красные «Очистить страницу» и «Отправить в корзину».

### Меню документа во вкладке (`39`)
- Тап по ⌄ у активной вкладки открывает поповер:
  - верхнее поле — название (переименование);
  - карточка свойств: Расположение (Документы), Последнее изменение («32 минуты назад»), Стр. («4 из 5»), Доступ по ссылке (Отключено), Язык заметок (Определять автоматически);
  - синие действия: Преобразовать в цифровую доску, Переместить в другую папку, Открыть в новом окне; красная «Закрыть другие вкладки».

### Фигуры (`27`)
- Подпанель: режим «фигуры от руки» | коннектор-ломаная (выбран) | коннектор-кривая | квадрат, круг, треугольник, ромб, скруглённый прямоугольник | толщина | цвет.

### Элементы (`28`)
- Поповер «Элементы», справа кнопка разворота в боковую панель.
- Сегменты Stickers / GIFs. Раздел «Недавние» — сетка стикеров.
- Нижняя полоса категорий: недавние (синяя), ленты, облака, канцелярия, …, магазин, «+» (свой стикер).

### Клейкие заметки (`29`)
- Подпанель: 9 пастельных цветов (красный, оранжевый, жёлтый — выбран, зелёный, бирюзовый, голубой, сиреневый, розовый, бежевый) | белый.

### Лазерная указка (`32`)
- Выбранный инструмент с ⌄ (тип: точка/след). Своей подпанели нет.

### Поиск в документе (`40`)
- Открывается в левой панели вместо «Страницы». Шапка: «…», заголовок «Поиск», ×.
- Поле поиска с лупой, сразу фокус и клавиатура.
- Сегменты: Заметки / Структура. Пустое состояние — иллюстрация.

## Корзина (`41`)
- Открывается из меню аккаунта как большое модальное окно (sheet) поверх библиотеки.
- Шапка справа: красная капсула «Очистить», «Выбрать», синяя круглая ✓ (закрыть). Большой заголовок «Корзина».
- Строка «Фильтр: Все» и справа вид (сетка) и статус облака.
- Та же сетка, что в библиотеке (5 колонок в ландшафте): документы и папки с названием ⌄, датой, бейджем «Только чтение».

## Шаблоны блокнотов (`42`–`42d`)
- Открываются из меню аккаунта («Управление шаблонами блокнотов») как большое модальное окно. Слева сверху круглая ×, заголовок «Шаблоны блокнотов» по центру.
- Верхняя часть — шаблон по умолчанию для новых блокнотов:
  - слева карточка «БУМАГА» с превью выбранной бумаги и подписью («В клетку»), под ней синяя черта;
  - справа переключатель «Обложка» и группа «ШАБЛОНЫ БУМАГИ»: «Размер» (`Стандартный, Книжная ⌄`) и «Цвет» (кружок + `Белый ⌄`).
- Поповер «Размер» (`42b`): сегменты Книжная / Альбомная, затем список Стандартный (✓), A3, A4, A5, A6, A7 (iPhone), US Letter, Tabloid…
- Ниже прокручиваемый каталог «Шаблоны бумаги» со ссылкой «Изменить» справа. Разделы, в каждом сетка по 5 карточек (превью, название, три кружка цвета бумаги: жёлтая / белая / тёмная):
  - Основные: Пустая страница, В точку, В клетку (выбрана — синий ✓ на превью), Линованная узкая, Линованная широкая;
  - Писчая бумага: Корнельская бумага, Правовые документы, Одна колонка (микс), Одна колонка, Три колонки;
  - Планировщик: Задачи, Календарь на месяц B, плитка «+ Импортировать» (пунктир);
  - Нотная бумага: Нотная бумага, Нотная бумага для гитары, Табулатура для гитары, «+ Импортировать».
