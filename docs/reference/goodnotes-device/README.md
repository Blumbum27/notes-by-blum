# Goodnotes на iPad: как устроен интерфейс

Снято с iPad Air 11" (M3), iPadOS 26.7.2, Goodnotes 7.1.14, русская локализация, бесплатный тариф. Логические размеры: портрет 820×1180 pt, альбом 1180×820 pt. Скриншоты сделаны через WebDriverAgent. В `NN-name.tree.txt` рядом с каждым скриншотом лежит дерево accessibility: тип, подпись и рамка в pt.

Файлы — личный референс. В приложение они не копируются. В кадрах видны реальные документы владельца.

## Библиотека

### Каркас
- Шапка: слева круглая кнопка «Показать боковое меню». Справа в одной плавающей капсуле «Поиск», «Уведомления» и аватар «Меню».
- Крупный заголовок раздела («Документы»).
- Строка управления под заголовком. Слева «Фильтр» с текущим значением («Все»). Справа синяя капсула «+ Создать», затем кнопка вида (иконка сетки или списка, `Сгруппированные опции: сортировка, параметры вида, выбор файлов`), разделитель и статус облака.
- Внизу плашка-предупреждение о резервном копировании («Резервное копирование приостановлено…», кнопки «Не сейчас» и «Войти в Google Drive»). У нас аналог — локальное напоминание о резервной копии, без облака.

### Боковое меню (`01-library-sidebar`)
- Плавающая скруглённая панель шириной 320 pt. Сверху справа кнопка «Скрыть боковое меню».
- Пункты с иконкой и подписью: Документы, Избранное, В общем доступе, Маркетплейс. У активного пункта серая скруглённая подложка и цветная иконка.
- Корзины в меню нет: она в меню аккаунта.
- В портрете панель сдвигает контент вправо и сетка перестраивается в 2 колонки. Это не оверлей.

### Сетка (`01`, `06`)
- Портрет — 4 колонки, ячейка 180×267 pt, превью 160×172.
- Папка — цветная иконка папки. Документ — обложка или первая страница с тенью.
- Звезда «избранное» в правом верхнем углу превью: контурная или залитая красным.
- Под превью: название + `⌄` (кнопка меню элемента), дата изменения («Сегодня, 11:53», «1 сент. 2026 г., 22:37»), опционально статус «Только чтение» с иконкой перечёркнутого карандаша.
- Угловой бейдж синхронизации на превью — облачный, нам не нужен.

### Список (`06-library-list`)
- Строка: маленькое превью, название, дата. Справа `⌄` (меню), звезда, для папок `›`. Разделители между строками.

### Фильтр (`03-library-filter`)
- Всплывающее меню: Все / Документы / Папки, у выбранного галочка.

### Вид и сортировка (`05-library-view-options`)
- Меню из трёх групп:
  - «Выбор элементов» (режим множественного выбора);
  - Сетка / Список;
  - Дата создания / Последнее изменение / Имя / Тип.
- У активной сортировки галочка и стрелка направления ^. Повторное нажатие меняет направление.

### Создать (`04-library-create`)
- Поповер под кнопкой. Верхний ряд плиток: Блокнот, Цифровая доска, Текстовый док-т. Второй ряд: Импорт, Быстрая аудиозапись.
- Затем список: QuickNote, Сканировать документы, Набор карточек, Изображение, Сделать фото. Отдельно: Папка. Отдельно: Импорт из облачных хранилищ.
- На бесплатном тарифе у платных пунктов бейдж-замок. У нас ограничений нет.

### Меню документа (`07-item-menu-document`)
- Поповер. Сверху редактируемое поле с названием (переименование). Затем: Дублировать, Переместить, Преобразовать в цифровую доску, Открыть в новом окне, Экспорт, Ссылка общего доступа, Добавить защиту, Отправить в корзину (красным).

### Меню папки (`08-item-menu-folder`)
- Поле названия.
- Группа: Настроить цвет, Добавить значок (эмодзи-значок на папке).
- Группа: Переместить, Открыть в новом окне, Экспорт, Отправить в корзину.

### Меню аккаунта (`09-account-menu`)
- Поповер справа.
- Карточка профиля («Бесплатная версия», «Учётная запись») и промо подписки — нам не нужны.
- Группа: Настройки, Управление шаблонами блокнотов, Облако и рез. копии, Integrations, Корзина.
- Группа внешних ссылок: Руководство пользователя, Сообщить о проблеме, Оценить в App Store.

### Избранное (`02-favorites`)
- Тот же каркас с заголовком «Избранное», без «+ Создать».
- Показывает избранные папки, документы и отдельные страницы. Страница — это превью страницы с красной закладкой и мини-обложкой документа в углу; подпись «Название - Р.2».

## Настройки (`10`–`14c`)
- Модальное окно 540 pt по центру поверх затемнённой библиотеки. В шапке круглая кнопка «назад» ‹ слева, заголовок по центру, синяя круглая «Готово» ✓ справа. Группы — белые скруглённые карточки на сером фоне, подписи групп серым.
- Корень (`10-settings`). Группа 1: Редактирование документов, Конфиденциальность, Стилус и Palm Rejection. Группа 2: Язык, Рукописный ввод, Ассистент-корректор. Группа 3: Параметры уведомлений, Обратная связь и опросы, Устранение неполадок.
- **Редактирование документов** (`11`, `11b`):
  - переключатели: Автоблокировка экрана, Меню статуса iOS, Потянуть для добавления страницы, Показывать номер страницы, Показать слои;
  - выбор «Направление прокрутки»: Вертикально / Горизонтально;
  - переключатель «Превью штриха по наведению» (Pencil hover);
  - группа «Панель инструментов»: Настройка панели инструментов ›, «Расположение инструментов» (Вверху/…), «Позиция отмены и возврата» (Слева/…);
  - переключатели: Автопереход; Автоматически открывать новые импортированные документы; Открывать в новых вкладках; Преобразовать закладки в элементы структуры.
- **Стилус и Palm Rejection** (`12`): Стилус = Apple Pencil ›. Блок настроек Apple Pencil: «Прокрутка одним пальцем» и «Отключить». Блок Palm Rejection: «Чувствительность» (Высокая ›) и «Положение руки» с иллюстрацией.
- **Рукописный ввод** (`13`): «Индексация PDF и рукописных заметок» (поиск по содержимому), «Отправить рукописный образец».
- **Настройка панели инструментов** (`14`, `14b`, `14c`): сегменты «Инструменты» / «Аксессуары».
  - Инструменты: список с красным «удалить», иконкой, названием и ручкой перетаскивания. По порядку: Инструменты для письма («Настроить ›»), Ластик, Фигуры, Элементы, Клейкие заметки, Изображения, Текст, Лазерная указка. Подсказка «Хотя бы один инструмент должен оставаться видимым». При нехватке места часть уходит в меню «ещё». Кнопка «Восстановить стандартную панель».
  - Аксессуары: на панели «Записать и сделать сводку». Другие: Показать записи, Окно масштаба, Линейка, Time Keeper. Кнопка «Восстановить стандартные аксессуары».
- Свайп вниз по окну закрывает настройки.

## Редактор

### Шапка с вкладками (`20-editor-readonly-pdf`)
- Верхняя полоса (цвет темы, тёмно-синий) с вкладками открытых документов. Слева «Home» (домик). Каждая вкладка: название с обрезкой «…» и × справа. У активной белый фон, и рядом с названием ⌄ (меню документа).
- Вторая строка — панель документа:
  - слева: «Боковое меню» (миниатюры/структура), «Поиск», чип режима «Только чтение» / «Режим редактирования» (переключатель чтение ↔ правка);
  - справа: «Поделиться», «Ещё» (…).
- PDF-документ «Только чтение» — режим без панели инструментов.
- Страницы листаются вертикально и центрируются на сером фоне. Внизу слева плашка «1 из 264».
